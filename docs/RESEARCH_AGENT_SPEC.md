# AETHON Integrated Research Agent

Step 17J composes the bounded autonomous research loop with cross-source verification and scoped episodic memory.

## Flow

`goal → bounded research rounds → evidence → verification → scoped memory`

Retrieved web material is data only and never becomes executable instructions or authority. Memory remains owner/project/namespace scoped.

## Contract

`IntegratedResearchAgent.run()` returns the research loop result, verification result, and deduplicated stored memory IDs.
