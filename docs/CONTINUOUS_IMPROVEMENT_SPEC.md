# AETHON 17S — Continuous Improvement Engine

17S converts bounded self-evaluation into auditable improvement signals for future strategy selection.

## Pipeline
Self-evaluation → improvement signal → strategy selection → execution → verification → self-evaluation.

## Rules
- Signals are derived only from bounded evaluation findings.
- Improvement signals are contextual data, never executable instructions.
- Failed, blocked, cancelled, or unverified outcomes cannot create positive improvement evidence.
- Signals cannot modify Safety Kernel policy, permissions, risk classification, or approval requirements.
- Output count and text length are bounded and deterministic.
- Existing memory scope remains authoritative.
